# Tally
Low-profile F1 timing sheet (qualifying + race) using F1's unofficial live-timing feed.

## Build
1. Create a GitHub repo, upload everything in this folder (keep the `.github` folder).
2. Actions tab -> "Build APK" -> Run workflow.
3. Download the `tally-apk` artifact, unzip, install app-debug.apk on your phone.

## Use
- Double-tap the title to flip to a boring notes page; double-tap that page to come back.
- Menu (three dots): dark/light, reconnect.
- Feed only exists during live sessions. Between sessions it shows nothing.
